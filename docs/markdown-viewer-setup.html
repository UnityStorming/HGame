为 Markdown 文档开启阅读排版

浏览器直接打开 MD 时，通常显示原始文本。安装 Markdown Viewer 并允许访问本地文件后，即可阅读排版后的标题、表格和代码块。文档仍只维护原始 MD，修改后刷新页面即可。

  1. 01

    安装 Markdown Viewer

    用你阅读文档的浏览器打开对应商店，在商店页面点击安装并按提示确认。

    Chrome · 打开扩展商店 ↗Chrome Web Store / Markdown Viewer Edge · 打开扩展商店 ↗Microsoft Edge Add-ons / Markdown Viewer

    以上链接来自 simov/markdown-viewer 官方项目。商店无法访问时，可查阅项目 README 中的安装说明。

  2. 02

    打开扩展详情

    将下面与你的浏览器对应的地址复制到地址栏，按 Enter：

    • Chrome：chrome://extensions
    • Edge：edge://extensions

    找到 Markdown Viewer，确认扩展已启用，然后点击“详情”。

    浏览器内部设置地址需要在地址栏打开，普通网页中的链接可能无法跳转。

  3. 03

    允许访问本地文件

    在扩展详情中开启“允许访问文件网址”或“允许访问文件 URL”，英文为 Allow access to file URLs。不同浏览器版本的中文名称可能略有差异。

    这是本地阅读的关键设置：HGame 文档从工程目录打开，扩展需要此权限才能渲染这些 MD 文件。

  4. 04

    打开文档，验证排版

    点击下方按钮打开现有架构文档。若之前已打开该文件，安装配置后刷新一次。

    打开架构文档，验证阅读效果 ↗

    • “HGame 架构与项目结构”显示为大标题，开头的 # 不再作为正文出现。
    • “程序集划分”中的内容显示为表格。
    • 代码块保持等宽字体与换行，原始围栏符号不再作为正文出现。

    验证成功后，返回索引继续阅读其他文档。每位同事在自己的浏览器中配置一次即可，工程可以 Clone 到不同目录。

可选：目录与自动刷新

在浏览器扩展菜单中打开 Markdown Viewer，进入 Content 内容选项，可按需要开启：

TOC · 文档目录

根据标题生成目录，便于跳转到长文档的不同章节。

Autoreload · 自动刷新

本地 MD 保存后自动重新加载。保持默认关闭时，手动刷新也能看到最新文档。

常见问题

安装了扩展，为什么仍显示原始文本？

检查当前浏览器中的扩展是否启用、是否已开启本地文件访问，并刷新 MD 页面。若扩展切换到了 Raw 原始视图，请切回渲染视图。多个 Markdown 扩展同时启用时，可暂时关闭其他同类扩展后重试。

换电脑或换浏览器后，需要重新设置吗？

需要在实际阅读文档的浏览器中确认扩展已安装，并检查本地文件权限。索引和验证文档使用相对路径，工程位置改变后仍可使用。

修改文档后，如何看到最新内容？

保存 MD 后刷新浏览器页面，或开启 Autoreload 自动刷新。索引仍直接链接原始 MD，因此没有额外的 HTML 文档副本需要同步。
